# Contributing a label set

A label set is the community's shared markers for a recording: your markers
plus the facts that tie them to exactly one YouTube video. Contributing one
happens entirely in the app — nothing to download, nothing to set up, no
GitHub account.

## From the app

You marked a public performance on YouTube and want every student to start
from your markers. The whole path is inside the app:

> **Playback is read-only; marking is not.** A student practising a
> recording never changes it (ADR-0003), and the surface that authors a
> project's markers is a page of its own (ADR-0007): place a marker at the
> playhead, move it, name it, and lay out the movements it belongs to. The
> **Markings** button on the project's row in your projects list opens it,
> as does the **Markings →** link beside a project's markers.

1. **Open the project you want to contribute.**
2. **Sign in with Google.** The only account the app ever asks for. Reading
   label sets never requires one; publishing does.
3. **Mark the recording.** A project you own is yours to fill. Play it and
   press `M` where a landmark goes by — the marker falls at the playhead —
   then correct anything that landed early or late, by nudging it or typing
   the time.
4. **Submit your label set.** One step in the app. Your markers for this
   video go to the Commons as a **pending** submission — visible to you,
   not yet to anyone else. Submissions are limited to three per 7 days,
   resubmissions included.
5. **Await review.** A maintainer listens and checks the markers, exactly as
   they would check any contribution. A set the maintainer denies comes
   back to you with its row marked **Rejected** — submit it again, and it
   returns to review.
6. **Published.** Your label set loads for every student who opens the
   video. Updating the set returns it to pending and goes through review
   again (a contributor whose past sets were accepted publishes updates
   immediately).

A label set is facts about a recording (like a table of contents), not
copyrightable expression — sharing your own markers is unproblematic. Publish
only markers you placed yourself on this exact performance: markers made
against one recording never transfer to another, and the app says so plainly.
